## Completed

Step A0 — the push-to-talk harness is real:

- **Global hotkey** `Ctrl+Option+Space` (default, single constant `audio::DEFAULT_HOTKEY`;
  product decision recorded in notes.md: everything becomes user-configurable later). Registered
  Rust-side with `tauri-plugin-global-shortcut` 2.3.2 via `on_shortcut` in `setup`; `Pressed` /
  `Released` map to start/stop capture — a true hold-to-talk, not tap-to-toggle.
- **Microphone capture**: `cpal` 0.18.2 + `hound` 3.5.1. Samples are buffered in memory (i16,
  I16/F32/U16 input formats handled) and written on release as a 16-bit WAV with the device's
  native rate/channels into the OS app-data `recordings/` dir (never the repo). 120 s sample cap.
- **Seam addition (additive)**: `PolarisEvent::AudioCaptured { path, durationMs }`, mirrored in
  `interfaces/` and in `docs/interfaces.md` (bumped to v0.2) — **flagged for Owner B's review**.
- **Button fallback**: `capture_start` / `capture_stop` Tauri commands mirror the hotkey path;
  `begin_capture` is idempotent so hotkey and button can race safely. The UI's recording
  indicator is driven by wire events (`hotkey`, `audio_captured`, `error`), not local state.
- **Hygiene**: the temporary `dev_self_test` command is deleted (Rust + TS + UI); the log pane's
  hotkey/line labels were updated to push-to-talk semantics.
- **TCC**: partial `app/src-tauri/Info.plist` with `NSMicrophoneUsageDescription` (Tauri
  auto-merges it for bundled builds).
